# WHO Global Tuberculosis Report 2026

Code and data used to develop the World Health Organization's _Global tuberculosis report 2026_. The report was published on 12 November 2026 at https://www.who.int/teams/global-programme-on-tuberculosis-and-lung-health/tb-reports/global-tuberculosis-report-2026/

This repository brings together a number of linked sub-projects to generate TB burden estimates and to produce the report's web pages and PDF. The sub-projects are linked through the use of common data files, both as inputs and as generated outputs to be used by other sub-projects.


# About this repository

This repository is published and maintained by the World Health Organization (WHO), Department for HIV, Tuberculosis, Hepatitis & Sexually Transmitted Infections. It provides publicly released TB data, the accompanying data dictionary, and code supporting _Global tuberculosis report 2026_ at https://www.who.int/teams/global-programme-on-tuberculosis-and-lung-health/tb-reports/global-tuberculosis-report-2026/.

The data comprise information reported by countries and territories to WHO and TB burden estimates generated by WHO. WHO acknowledges the contributions of national tuberculosis programmes and other national authorities that provided the underlying data.

Official data page: https://www.who.int/teams/global-programme-on-tuberculosis-and-lung-health/data

# Folders


* **data**: Datasets used for the report:

  * **datahub**: Selected indicators downloaded from the WHO Health Data Hub, including UHC service index
  
  * **gf**: Global Fund data on pledges from donors
  
  * **gho**: Selected indicators downloaded from the WHO Global Health Observatory, including BCG vaccination coverage and catastrophic health expenditure

  * **gtb**: R binary datasets extracted from the WHO global TB database. GTB data are now split into two categories: snapshots of country-reported data and other data such as survey results. Whenever a new set of snapshots are downloaded they are saved in a new subfolder:

    * **other**: Country lists, population estimates, reference lists, survey results and external indicators
    
    * **snapshot_yyyy-mm-dd**: Snapshot of country-reported data

  * **ilo**: Social protection indicators from the International Labour Organization
  
  * **imf**: Economic data from the International Monetary Fund
  
  * **kff**: Economic data from the Kaiser Family Foundation 

  * **mortality**: VR data from the WHO Mortality database
  
  * **nhe**: National Health Accounts data from the WHO Global Health Expenditures Database
  
  * **oecd**: Economic data from the Organisation for Economic Co-operation and Development
  
  * **pcs**: Summary results from completed patient cost surveys
  
  * **ps**: Summary results from prevalence surveys not available in the WHO global TB database

  * **uhcsci**: Data from the SDG database

  * **unaids**: HIV estimates from UNAIDS
  
  * **unore**: UN operational rates

  * **unsdg**: SDG indicators from the UN SDG database

  * **wb**: Economic data from the World Bank

* **disaggregation**: Pete Dodd's R scripts to estimate incidence and mortality disaggregated by age group and sex. NOTE: This folder is currently not available because incidence estimates for India are under review.

* **doc**: Reference documents such as a guide to the WHO global TB database views, variable names and how they relate to the web-based data collection form used by countries to report data to WHO. 

* **drtb**: Pete Dodd's R and Stan scripts to estimate drug-resistant TB burden.  NOTE: "/drtb/output" in this folder is currently not available because incidence estimates for India are under review.

* **dynamic**: Nim Arinaminpathy's Matlab code for dynamic modelling of TB incidence and mortality for the period 2020-2025 in selected countries. NOTE: This folder is currently not available because incidence estimates for India are under review.

* **finance**: Takuya Yamanaka's R code (converted from Stata code developed over many years by many people) for analysing TB financing data.

* **inc_mort**: Mathieu Bastard and Philippe Glaziou's R scripts to produce estimates of TB incidence and mortality. NOTE: "/inc_mort/analysis" in this folder is currently not available because incidence estimates for India are under review.

* **lives_saved**: Takuya Yamanaka and Philippe Glaziou's R scripts to produce estimates of the number of death averted by TB treatment and ART since 2000.

* **report**: R Markdown scripts by Mathieu Bastard, Irwin Law and Takuya Yamanaka to generate tables, static figure, interactive Kendo UI charts and text for the Global tuberculosis report web pages and the report PDF. 


# Global tuberculosis database data sets

The following sections show the data object names chosen in previous years. If you use the `load_gtb()` function you don't need to know if a data object is part of a snapshot or other, nor does your code have to use the same object name.

For example, the following line loads the most recently saved snapshot of notifications into a dataframe / data table called `notifs`:
```
notifs <- load_gtb("tb")
```

## Snapshot data

* **access_wrd**: 

* **agg**: aggregated TB/HIV indicators

* **budget**: TB finance, budget

* **community**: Community engagement

* **diag_treatment**:  TB diagnosis and treatment

* **drs**: Routine drug resistance surveillance records

* **tb**: TB notifications

* **expenditure**: TB finance, expenditure

* **finance_short**: TB finance, budget and expenditure in short form

* **infection_ctrl**: TB infection control among healthcare workers

* **lab_diag**: TB laboratory and diagnostic services

* **ltbi**: Estimates of TPT coverage among children (numbers derived from reported data)

* **maftb**: Multisectoral accountability framework on TB

* **outcomes**: TB treatment outcomes

* **ppm**: Public-private mix and public-public mix (PPM) initiatives

* **prisons**: TB screening and notifications among people in prisons

* **monthly**: Provisional monthly or quarterly notifications

* **tbdeath**: VR data reported by countries

* **tbhiv**: TB screening, diagnosis and notifications among people living with HIV 

* **tpt**: TB preventive treatment

* **utilization**: TB finance, health service utilization

### Explanatory 

### Reference: countries, country groups, population and SDG indicators

* **cty**: Country and area names in 4 languages, their codes and WHO region and status

* **drfq**: DRS records used to estimate fluoroquinolone resistance among RR-TB patients

* **drhnew**: DRS records used to estimate HR-TB among new TB patients

* **drhret**: DRS records used to estimate HR-TB among previously treated TB patients

* **drnew**: DRS records used to estimate RR-TB among new TB patients

* **drret**: DRS records used to estimate RR-TB among previously treated TB patients

* **grp**: Country groups within each grouping theme (e.g. the 4 income groups of High, Upper Middle, Lower Middle and Low in the World Bank income classification)

* **grpmbr**: Countries belonging to each country group

* **pop**: UN Population Division population estimates

* **sdg**: SDG indicator data and codes relevant to TB incidence

* **sdgdef**: Full names of SDG indicators and their sources
